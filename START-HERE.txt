mori. 2.0 — С НУЛЯ: GitHub Pages + Gist-синхронизация

Тебе нужны: бесплатный GitHub-аккаунт, ПК с браузером, iPhone, интернет для первой настройки.
Firebase, Supabase, платные серверы и отдельные базы НЕ нужны.

ЧАСТЬ А. ВЫЛОЖИ САЙТ (НА ПК)
1. Распакуй ZIP в обычную папку.
2. Зайди на https://github.com/ и войди (или зарегистрируй аккаунт).
3. Открой https://github.com/new
4. Repository name: mori-notes. Visibility: Public. Нажми Create repository.
5. В пустом репозитории нажми uploading an existing file (или Add file → Upload files).
6. Открой распакованную папку mori-notes. Выдели ВСЁ её содержимое и перетащи в окно GitHub.
   НЕ загружай ZIP одним файлом и НЕ клади всё внутрь ещё одной папки mori-notes.
7. Проверь, что index.html, app.js, sync.js, styles.css, db.js, markdown.js,
   sw.js, manifest.webmanifest и папка icons загружаются. Нажми Commit changes.
8. Репозиторий → Settings → Pages → Build and deployment.
   Source: Deploy from a branch; Branch: main; Folder: /(root) → Save.
9. В Settings → Pages нажми Visit site, когда публикация завершится.
   Адрес примерно такой: https://ТВОЙ-НИК.github.io/mori-notes/

ЧАСТЬ Б. ПОЛУЧИ ТОКЕН (ОДИН РАЗ)
10. Открой https://github.com/settings/tokens/new
11. Note: mori sync. Expiration: выбери срок действия, например 90 days.
12. В разрешениях (scopes) поставь ТОЛЬКО галочку gist — НЕ repo.
13. Внизу нажми Generate token; скопируй выданный токен ghp_... в безопасное место.
    GitHub покажет значение только один раз. НИКОМУ не присылай его.

ЧАСТЬ В. ПЕРВАЯ СИНХРОНИЗАЦИЯ (НА ПК)
14. Открой опубликованный сайт mori. по ссылке GitHub Pages.
15. Создай тестовую заметку. Нажми вверху «Синхронизировать».
16. Вставь токен из шага 13.
17. Придумай ОТДЕЛЬНЫЙ пароль шифрования длиной от 12 символов.
    Это НЕ пароль от GitHub! Запомни его, восстановить забытый пароль нельзя.
18. Нажми в окне «Синхронизировать».
    При успехе сайт автоматически создаст зашифрованный Gist. Ничего вручную создавать не надо.

ЧАСТЬ Г. ПОДКЛЮЧИ IPHONE
19. На iPhone открой в Safari ТОТ ЖЕ адрес сайта.
20. Нажми «Синхронизировать»; вставь ТОТ ЖЕ GitHub-токен и ТОТ ЖЕ пароль шифрования.
21. Нажми «Синхронизировать». Заметка с компьютера появится на айфоне.
22. Чтобы сделать иконку на главном экране: Safari → Поделиться → На экран «Домой» → Добавить.
    Если установленное PWA откроется с пустыми заметками, повтори внутри него шаги 20–21:
    iOS может держать отдельное локальное хранилище для приложения с экрана «Домой».

В ДАЛЬНЕЙШЕМ
- После редактирования на устройстве нажми «Синхронизировать».
- На другом устройстве тоже нажми «Синхронизировать», чтобы получить изменения.
- После перезапуска страницы нужно снова ввести пароль шифрования; токен сохраняется локально.
- Сами заметки доступны офлайн после первоначальной загрузки; для синхронизации нужен интернет.
- Время от времени скачивай резервную копию через меню mori.

ВАЖНО:
- GitHub Pages публикует КОД сайта в открытом репозитории, но НЕ твои локальные заметки.
- Gist является доступным по ссылке, поэтому mori. перед отправкой шифрует его содержимое.
- Токен даёт доступ к Gist твоего GitHub-аккаунта. Не вставляй его в файлы репозитория
  и не передавай никому. Если он утечёт — отзови в GitHub Settings → Tokens (classic).
- Если срок токена истечёт, создай новый с разрешением gist и введи на обоих устройствах.
