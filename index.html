Одна кнопка. Все заметки.

Данные хранятся у тебя на устройстве. Кнопка «Синхронизировать» объединяет заметки с зашифрованной копией в GitHub Gist.

1Создай GitHub Token (classic) ↗. Назови mori sync, отметь только gist и нажми Generate token.
2Вставь токен ниже и придумай отдельный пароль шифрования (12+ символов). Не потеряй его — без него облако не расшифровать.
3На iPhone вставь тот же токен и пароль. Архив обнаружится автоматически. Дальше — одна кнопка.

Ещё не подключено

Секретный Gist не является приватным. Поэтому mori. шифрует содержимое AES-256-GCM. Токен хранится локально и не попадает в репозиторий. Не вводи токен в чужих копиях сайта.

Импорт и копии.

Сохраняй свои записи независимо от облака. Файлы Markdown можно открыть в любом текстовом редакторе.

Даже с GitHub Gist регулярно скачивай резервную копию: облако не заменяет бэкап. Не публикуй личные копии в GitHub.
